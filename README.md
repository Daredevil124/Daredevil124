## Featured Projects

### [TablingTime Backend](https://github.com/PrashamMehta-04/TablingTime-Backend)
A Node.js and Express REST API for academic scheduling and timetable management. It includes JWT and Google authentication, role-based access for students, professors, and administrators, automated scheduling, room allocation, professor preferences, and CSV-based data processing.

**Tech:** Node.js, Express.js, MongoDB, Mongoose, JWT, Google OAuth

### [IICPC Distributed Benchmarking Engine](https://github.com/Daredevil124/Benchmarker)
A distributed benchmarking and hosting platform designed to evaluate contestant infrastructure under high load. It combines isolated code execution, concurrent bot fleets, Redis-based messaging, telemetry collection, and live leaderboard updates.

**Tech:** Go, React, Vite, Redis, Docker, Docker Compose, WebSockets

### [BattleWorld Job Portal](https://github.com/PrashamMehta-04/Doom-s-BattleWorld-Recruitment)
A Marvel-inspired recruitment platform with separate recruiter and applicant roles. Recruiters can post jobs and review applications, while accepted applicants gain access to real-time chat, video interviews, and automated email invitations.

**Tech:** React, Node.js, Express.js, MongoDB, Socket.IO, WebRTC, Vercel, Render
